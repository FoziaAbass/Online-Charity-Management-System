# Online-Charity-Management-System
a web-based platform that links donors with charity organizations in Nairobi. The system will provide secure registration and login features for both donors and charities, allowing users to create and manage profiles and fundraising campaigns. Donors will be able to browse different organizations, view key information such as missions and funding goals, and contribute directly to selected causes. The platform will also support anonymous donations to protect user privacy and offer multiple secure payment options. Overall, the system is intended to expand the reach of charities and help them achieve their fundraising objectives more effectively
